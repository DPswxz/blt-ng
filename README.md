# BLT · TCL 65P11 适配版

本仓库是在 [kkkunny/blt](https://github.com/kkkunny/blt) 基础上，为 **TCL 65P11 电视**调整的个人适配版本，应用名称仍为 **BLT**。

感谢原作者及贡献者提供开源项目。本版本沿用原项目的 Flutter 界面、电视遥控导航和客户端基础能力，在此基础上补充播放兼容性和个人常用功能。原项目介绍、原版功能、截图及上游更新，请直接查看[原版 GitHub 仓库](https://github.com/kkkunny/blt)。本仓库仅说明适配改动，不代表原作者维护，也不是哔哩哔哩官方客户端。

## 修改基线

基于原版 **v0.12.1**，起始提交为 [`e92a2ff83aefc09cdc97b224a36645feb14c53f8`](https://github.com/kkkunny/blt/commit/e92a2ff83aefc09cdc97b224a36645feb14c53f8)。该版本是本次修改的基线，不表示本仓库始终同步上游最新代码。

本适配仓库：[DPswxz/blt-ng](https://github.com/DPswxz/blt-ng)。

## 适配设备与播放调整

主要针对实际测试的 **TCL 65P11 / T982 平台 / Android 11 / ARMv7 系统**。其他电视型号与固件尚未充分验证。

- 增加 Android Media3 ExoPlayer 播放路径，使用原生 SurfaceView 和系统硬件解码，改善此设备上原播放路径的卡顿及部分 codec 打开失败问题。
- 自动模式优先选择硬件支持的编码，保留手动选择 ExoPlayer、MPV 及相关解码模式的入口。
- 默认进入视频选择普通 1080P，可在设置中改为 4K 或较低画质；结合实际可用视频流、解码能力与播放错误进行回退。保留编码偏好选择。
- 播放中显示平台实际提供的可选画质，增加 4K 档位支持。画质取决于片源、账号权限及设备能力，登录不等于拥有会员画质权限。
- 增加音轨选择，保留弹幕并调整播放器内设置的操作方式。弹幕支持顶部 5%/10%/25%/50% 显示区域（默认10%）和透明度调节，选择即时生效并保存。

播放优化以这台电视的实测为依据，不能保证所有片源、编码及高码率 4K 都流畅。ADB 截图异常也不能直接作为电视实际花屏的结论。

## 新增与完善的功能

### 个人页面与账号

- 点击侧栏头像进入个人页面，首页位于头像下方的第一个导航位置。
- 个人页面依次提供追番追剧、收藏夹、稍后再看；支持进入订阅番剧选择分集，进入不同收藏夹浏览并播放视频。收藏夹没有专用封面时，自动使用其中有效视频的封面。
- 账号管理支持扫码添加账号、保存多个账号、快速切换和退出指定账号；切换与退出均有二次确认，取消原来的双击头像退出行为。
- 展示 B 站等级、大会员状态及到期信息；账号的登录凭据分别保存，切换后刷新个人数据。

### 视频详情与互动

- 增加主评论及二级回复浏览、评论点赞与点踩，调整评论层级、两行摘要和相关推荐空间分配。
- 视频点赞、投币、收藏、稍后再看使用统一的高亮状态；移除视频点踩按钮。
- 增加投币数量选择与确认，提交成功后更新投币状态。投币无法撤回，数量和可操作范围以平台返回结果为准。
- 收藏可选择目标收藏夹，已收藏时可从相应收藏夹移除；稍后再看支持添加和取消，并在详情返回后刷新对应列表。
- 调整简介读取、信息卡边距和操作按钮布局。

### 遥控与界面

- 统一侧栏、按钮、选中项和焦点的粉色主题，优化遥控焦点辨识与多分辨率布局。
- 设置页在主界面内切换并保留侧栏，完善菜单滚动及选项显示。
- 增加首页退出确认，调整搜索返回行为，避免误退出应用。

## 构建与验证

使用 Flutter 与 Android 工具链构建；本机适配脚本为 `build-tcl.ps1`，默认产出 ARMv7 APK。适配包应用 ID 为 `com.kkkunny.blt.tcl`，显示名称仍为 BLT，可与原版区分安装。

存储迁移、账号隔离、接口解析、互动确认流程和电视布局有对应自动化测试。真实电视已验证个人列表、账号信息及部分播放场景；多账号切换使用模拟账号测试，仍需结合实际账号与网络验证。
