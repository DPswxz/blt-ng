# BLT · TCL 65P11 适配版

本仓库是在 [kkkunny/blt](https://github.com/kkkunny/blt) 基础上，为 **TCL 65P11 电视**调整的个人适配版本，应用名称仍为 **BLT**。

感谢原作者及贡献者提供开源项目。本版本沿用原项目的 Flutter 界面、电视遥控导航和客户端基础能力，在此基础上补充播放兼容性和个人常用功能。原项目介绍、原版功能、截图及上游更新，请直接查看[原版 GitHub 仓库](https://github.com/kkkunny/blt)。本仓库仅说明适配改动，不代表原作者维护，也不是哔哩哔哩官方客户端。

当前适配版版本：**v1.0.22**，后续适配更新从此版本号递增。

番剧详情与普通视频共用操作按钮、简介和视频卡片样式；选集位于评论上方，点击切换分集信息，再次点击已选分集播放，并支持观看记录定位。

历史中的番剧分集统一进入番剧详情，定位点击的分集，显示该集评论、操作数据和投稿 UP 主。

## 修改基线

基于原版 **v0.12.1**，起始提交为 [`e92a2ff83aefc09cdc97b224a36645feb14c53f8`](https://github.com/kkkunny/blt/commit/e92a2ff83aefc09cdc97b224a36645feb14c53f8)。该版本是本次修改的基线，不表示本仓库始终同步上游最新代码。

本适配仓库：[DPswxz/blt-ng](https://github.com/DPswxz/blt-ng)。

## 适配设备与播放调整

主要针对实际测试的 **TCL 65P11 / T982 平台 / Android 11 / ARMv7 系统**。其他电视型号与固件尚未充分验证。

- 增加 Android Media3 ExoPlayer 播放路径，使用原生 SurfaceView 和系统硬件解码，改善此设备上原播放路径的卡顿及部分 codec 打开失败问题。
- 自动模式优先选择硬件支持的编码，保留手动选择 ExoPlayer、MPV 及相关解码模式的入口。
- 默认进入视频选择普通 1080P，可在设置中改为 4K 或较低画质；结合实际可用视频流、解码能力与播放错误进行回退。保留编码偏好选择。
- 播放中显示平台实际提供的可选画质，增加 4K 档位支持。画质取决于片源、账号权限及设备能力，登录不等于拥有会员画质权限。
- 增加音轨选择，保留弹幕并调整播放器内设置的操作方式。弹幕支持顶部 5%/10%/25%/50% 显示区域（默认10%）和透明度调节，选择即时生效并保存。

播放优化以这台电视的实测为依据，不能保证所有片源、编码及高码率 4K 都流畅。

## 新增与完善的功能

### 首页栏目

- 推荐视频菜单支持“内容不感兴趣”和“不想看此UP主”，按账号在本地保存过滤偏好，刷新后继续生效；不修改 B 站网页或其他客户端的推荐设置。
- 首页提供推荐、热门、番剧三个栏目，支持遥控切换与分页。番剧可进入分集播放，播放权限由平台根据片源和账号状态判定。

### 个人页面与账号

- 点击侧栏头像进入个人页面，首页位于头像下方的第一个导航位置。
- 个人页面依次提供追番追剧、收藏夹、稍后再看；支持进入订阅番剧选择分集，进入不同收藏夹浏览并播放视频。收藏夹没有专用封面时，自动使用其中有效视频的封面。
- 账号管理支持扫码添加账号、保存多个账号、快速切换和退出指定账号；切换与退出均有二次确认，取消原来的双击头像退出行为。
- 展示 B 站等级、大会员状态及到期信息；账号的登录凭据分别保存，切换后刷新个人数据。

### 视频详情与互动

- 增加主评论及二级回复浏览、评论点赞，调整评论层级、两行摘要和相关推荐空间分配。
- 视频点赞、投币、收藏、稍后再看使用统一的高亮状态；移除视频点踩按钮。
- 投币入口保留数量统计，点击提示“功能暂未开放”，不提交投币请求。
- 收藏可选择目标收藏夹，已收藏时可从相应收藏夹移除；稍后再看支持添加和取消，并在详情返回后刷新对应列表。
- 调整简介读取、信息卡边距和操作按钮布局。

### 内存与资源管理

- 搜索页离开后销毁，进入视频详情前清空结果，仅保留搜索历史。
- 主页面只保留有限数量的最近页面，首页栏目按需重建；内存紧张时回收非当前页面，后台页面暂停动画。
- 图片按显示尺寸请求缩略图并限制解码大小；内存图片缓存预算48MiB/120项，Skia图形资源缓存预算48MiB，磁盘图片缓存最多160项，下载并发限制为4。页面淘汰时主动释放不用的图片缓存，保留磁盘缓存供再次进入时复用。
- 页面退出时取消未完成的数据请求，减少快速切页后的无效加载；播放状态只在变化时推送，视频缓冲设置有明确字节目标。

### 番剧与列表详情

- 首页番剧及追番追剧共用详情页，展示简介、评分、地区年份、统计和演职员资料；支持追番/取消追番、追剧/取消追剧，选集同步切换封面和对应分集评论。
- 进入子页面保留父列表的滚动位置，返回后恢复到之前点击的入口；刷新登录凭据时保留设备标识，投币入口暂不开放。

### 播放完成提示

- 不循环时自然播放结束显示轻量淡入完成界面，默认聚焦“从头播放”；可归零重播、返回详情或手动进入下一集。单个循环不显示完成界面。番剧播放器接收完整选集，各集使用独立播放标识和进度，最后一集不显示下一集按钮。

### 遥控与界面

- 收藏夹、番剧等列表进入后聚焦首项；有返回按钮时，返回键先聚焦按钮，确认后返回上一级。

- 统一侧栏、按钮、选中项和焦点的粉色主题，优化遥控焦点辨识与多分辨率布局。
- 设置页在主界面内切换并保留侧栏，完善菜单滚动及选项显示。内容区向左返回侧栏时固定聚焦当前页图标，个人页面回到头像，不按控件高度就近跳转。
- 应用仅从侧栏“退出”入口确认退出；主界面按返回保留当前栏目，搜索页仍可收起输入法。搜索框、历史与热搜整体居中，确认切换到搜索页后，侧栏向右进入搜索框；选中时不唤起输入法，确认后才编辑，收起输入法后可用方向键离开；移除输入框右侧清除按钮。

## 构建

使用 Flutter 与 Android 工具链构建，通过 `flutter build apk --release --split-per-abi --target-platform android-arm` 产出 ARMv7 APK。适配包应用 ID 为 `com.kkkunny.blt.tcl`，显示名称仍为 BLT，可与原版区分安装。

原项目的基础介绍和上游资料请查看 [kkkunny/blt](https://github.com/kkkunny/blt)，并尊重原作者及所用依赖的许可与署名要求。
